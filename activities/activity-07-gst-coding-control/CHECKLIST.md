# Activity 07 checklist

- [ ] Step 1: Read the GST Scenario sheet and confirm the entity is GST-registered for the activity period.
- [ ] Step 2: Classify each source transaction as standard-rated, zero-rated, exempt, out-of-scope or requiring escalation.
- [ ] Step 3: Calculate expected GST for tax-exclusive and tax-inclusive examples using the workbook formulas.
- [ ] Step 4: Compare the expected treatment with the QuickBooks tax code available in the current Singapore company.
- [ ] Step 5: Enter or review the sample sales invoices and supplier bills using the approved tax codes.
- [ ] Step 6: Check that credit notes reverse the original GST treatment and period appropriately.
- [ ] Step 7: Review transactions without tax and unusual code-by-account combinations.
- [ ] Step 8: Trace a sample of input-tax claims to valid business-purpose supporting documents.
- [ ] Step 9: Record uncertain items in the Escalation Log rather than guessing a tax treatment.
- [ ] Step 10: Complete the GST Coding Review sign-off.

## Acceptance
- [ ] Every transaction has a supported classification
- [ ] Formula checks agree to system tax amounts
- [ ] Uncertain items are escalated
- [ ] Credits mirror original tax treatment
